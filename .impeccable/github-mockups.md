# GitHub mockups

Operate surface for Herdr users managing the selected repository. Extend the incumbent compact Git panel; compare navigation structures without changing production code.

## Direction contract

THESIS: Make repository, selected PR, and next useful action visible together. Compare current-branch focus, a persistent list with a separate preview, and an attention queue.

OWN-WORLD: Existing Herdr neutral surfaces, blue underline, 38px primary tabs, 28px controls, restrained status colors, native system typography, and Lucide-style SVGs. No dashboard metric tiles.

STORY: Find the relevant PR, inspect failed checks, extract unresolved reviews, and discover New PR with its generation instructions and template path.

FIRST VIEWPORT: An external prototype toolbar chooses three options, width, theme, and scenario. The app frame retains the Git panel on the right. The list/preview option keeps the selected row visible and opens details beside it.

FORM: Code-led interactive HTML inside an existing visual world. Seed: none (unavailable). Fictional content only, no remote actions.

FINISH: Verify all options, navigation, composer, instructions, empty/error states, and narrow widths in the browser. Keep the installed app unchanged.
